# AI Speedrun Frend (Minecraft 1.20.1, Fabric)

Каркас Fabric-мода: при входе игрока в одиночный мир мир автоматически открывается для LAN, спавнится бот `frend`, запускается спидран-движок. После завершения бот пишет время в чат и переходит в режим помощи, выполняя команды из чата (`!frend ...`).

## Требования
- Java 17+
- Gradle (или используйте gradle wrapper, если добавите)
- Fabric Loader 0.16.x
- Minecraft 1.20.1

## Сборка
1. Откройте папку проекта в терминале.
2. Запустите `gradle build` (или `./gradlew build`).
3. Готовый jar: `build/libs/ai-speedrun-frend-0.1.0.jar`.

## Установка
- Установите Fabric Loader для 1.20.1.
- Скопируйте `fabric-api-...jar` и ваш мод jar в `.minecraft/mods`.
- Запустите игру, создайте/откройте мир.

## Чат-команды
- `!frend help`
- `!frend come` — телепорт к игроку
- `!frend say <текст>`
- `!frend status`
- `!frend stop` / `!frend start`

## Ограничения
Полноценный «честный» спидран с реальной навигацией, крафтом, поиском твердынь и убийством дракона — огромная задача. В этой версии движок реализован как набор фаз с автоматическим прогрессом и ресурсами; это MVP. Навигацию/крафт можно углублять.
